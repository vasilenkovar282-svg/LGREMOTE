# LG Remote — iPhone
Нативный проект SwiftUI, iOS 16+. Предназначен для LG webOS 4.x, включая 43LK6000PLF. Без сторонних зависимостей и сервера.

## Установка
1. Распакуйте архив на Mac. Откройте LGRemote.xcodeproj в Xcode 15 или новее.
2. В Signing & Capabilities выберите свою Team (Apple ID). При конфликте измените Bundle Identifier.
3. Подключите iPhone, выберите его в Xcode и нажмите Run. При необходимости включите Developer Mode на iPhone. Бесплатная подпись Personal Team обычно действует 7 дней.
4. Подключите ТВ и iPhone к одной сети, включите телевизор. В настройках сети ТВ найдите IPv4. В приложении введите IP и разрешите доступ к локальной сети iOS. Подтвердите сопряжение на ТВ.

## Возможности
SSAP по ws://IP:3000, сохранение ключа по IP, громкость, каналы, выключение, указатель, клавиатура, цифровые кнопки, список приложений, YouTube и Lampa (если обнаружена в списке). Wake-on-LAN по UDP/9 на IP телевизора с введённым MAC; зависит от сетевого оборудования и режима ожидания ТВ. Unicast может не работать после истечения ARP-записи. Включите Mobile TV On, если поддерживается. 

## Ограничения
Проект рассчитан на старый незашифрованный локальный SSAP порт 3000, использовать только в доверенной домашней сети. TLS-порт 3001 не реализован. Автопоиск ТВ не реализован, ввод IP вручную. Возможности и разрешения зависят от прошивки; некоторые приложения могут отсутствовать в списке, ввод текста работает только в совместимых полях. Сопряжение требует согласия на ТВ. Исходники проверены синтаксическим парсером Swift, но сборка с iOS SDK, установка и проверка на физическом телевизоре не проводились. Это не подписанный IPA.

Если соединение не удаётся: проверьте IP, разрешение «Локальная сеть» в iOS, изоляцию клиентов Wi-Fi, LG Connect Apps на ТВ. Попробуйте удалить ключ сопряжения в приложении и подключиться снова. Если ТВ поддерживает только порт 3001, потребуется дополнить транспорт TLS с проверкой сертификата.

Справка по протоколу: https://github.com/MysterWolf/lg-remote ; https://developer.apple.com/documentation/foundation/urlsessionwebsockettask


## Сборка с Windows через GitHub
Создайте приватный репозиторий, загрузите содержимое этой папки (включая .github), откройте Actions → Build iOS IPA → Run workflow. После успешной сборки скачайте артефакт LGRemote-IPA, распакуйте и подпишите IPA через Sideloadly. Фото входит в ресурсы, поэтому рекомендуется приватный репозиторий.
